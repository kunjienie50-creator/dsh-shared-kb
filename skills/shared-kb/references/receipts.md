# 回执模板

用户在手机上读，**一屏内、先结论、无路径**。默认 6 行以内；超过就砍细节，别砍「待确认」。

## 单件

```
已收｜01_票据报销 · 差旅报销3480元（10-25）
要点：金额 3,480 元，发票号 0842-3311，待财务复核
```

## 批量（最常见）

```
已收 4 件｜01_票据报销 2 · 08_人脉联络 1 · 99_待分类 1
· 差旅报销3480元（10-25）
· 陈默名片11月看演示（10-25）
跳过 1 件：card.png 与已存名片同图，未重复落盘
待确认：IMG_2032.png 是培训证书还是会议签到？
```

## 全部重复 / 全部无效

```
0 件入库：这 3 张都是 10-25 已存过的
· 差旅报销3480元（10-25 已存）
· 陈默名片11月看演示（10-25 已存）
另 1 张纯表情包，已记跳过。
```

## 主动整理（待整理）

```
整理完：收 3 件（票据2、人脉1），删 2 件（重复/无信息），待整理已清空
· 差旅报销3480元（10-25）
· 陈默名片11月看演示（10-25）
待确认 1 件：IMG_2032.png 是培训证书还是会议签到？（暂放 99_待分类）
```

有删不掉的文件时补一句：`1 件没删掉：xxx.pdf 正被打开，下次再清`。

## 查库回答（用户问「我之前存的 XX 在哪」）

```
找到 2 件：
· 差旅报销3480元 → 01_票据报销，2026-10-25 收
· 差旅报销（9月）→ 01_票据报销，2026-09-28 收
要看内容我可以把要点发你。
```

## 敏感件

```
已收｜02_证件资质 · 身份证正反面（10-25）
含证件号码，只存在团队库，未发送、未外传。
```

## 风格要求

- 中文，短句，不用「已完成对……的分类存储」这类翻译腔。
- 条数用 `·` 开头，每行一件；同类多件可用「×2」合并。
- 只在真需要用户拍板时提问，且一轮最多一处。
- 不写绝对路径，不说「你去打开某个文件夹」。
- 用户嫌啰嗦时，压成两行：`收了 3 件（票据2、人脉1），1 件重复`。
