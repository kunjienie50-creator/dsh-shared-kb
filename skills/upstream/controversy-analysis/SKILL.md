# 争论分析：把争议还原成可判断的结构

> 不判人，判论证；不假平衡，也不硬凑超越。产出是对"分歧"的判断，不是对"人"的判决。

## 何时启用

- 用户贴一段争论、对线、评论区、访谈或论战文章，问"谁对""他们到底在争什么"。
- 用户抛出一个争议话题，要分析、要站队依据、要写反驳。
- 用户要在会议、文章或公开讨论中表态，需要一个能落地的判断。
- 用户问"这个说法站得住吗""这个论证哪里有问题"。

## 何时不要启用

- 只要事实摘要、会议纪要：直接摘要，不要套五步。
- 长对话要提炼知识地图、价值与方法论：用 `long-dialogue-knowledge`。
- 纯知识问题（X 是什么、为什么）：用 `knowledge-answer`。
- 材料只有一句口号、没有可辨认的论证：直接回答。
- 需要实时核查新闻事实：先声明边界，只做结构分析。

## 输入契约

| 需要 | 缺失时怎么办 |
|---|---|
| 争议文本或话题 | 问一次；仍无，按议题模式分析，声明"立场由我重构" |
| 双方材料 | 只有一方时，声明"只听了一面"；另一方按最强版本重构并标"重构" |
| 场合、受众、前因 | 按可见信息推断，标置信度 |
| 用户要什么（判断／理解／反驳／决策） | 默认给完整分析 |

## 工作流

### 0. 预检

模式（对话／议题）、材料完整性、锚点、语境、争议真伪（是否被制造或放大）、用户意图。
对话模式必须能定位到"第 N 段"；议题模式必须声明立场是重构的。

### 1. 定位争点（跳过这步，后面全是空转）

1. **命题化**："在 Z 条件下，是否应当 X，因为 Y"。写不出，先指出争议哪里模糊。
2. **是否同一问题**：四种常见错位——原则对可行、个案对制度、动机对效果、应然对实然。
3. **承重分歧类型**：事实／价值／定义／方法／利益／承认，只定一个；再做稳健性检查——改判为另一类型，结论会变吗？
4. **不可通约性检验**：先试着写一句双方都能接受的权衡；写得出就是权重分歧。
5. **预设审查**：问题本身预设了什么。
6. **争议形状**：一个问题两种答案／两个问题各说各话／不同层次被混在一起。

### 2. 立场重构（钢人）

每方一张卡：核心主张、优先价值、最强论证、依赖假设、代价承担者、可接受的反证、最强反驳与回应。

四条规则：**可辨认**（持该立场者能认领）、**禁稻草人**（不用最粗糙版本）、**不读心**（明说／强推断／弱推断）、**不对称要明说**（一边在事实层面明显更强就写出来）。

### 3. 证据状态与方法审计

- 三分事实：已确立／有争议／未知。
- 学科只在承重时进入：答不出"它支撑哪条主张、缺了会怎样"就删掉。
- 方法审计：自称用什么 → 实际做什么 → 让什么可见 → 遮蔽什么 → 最弱一环 → 对结论的影响。
- 至少指出两处事实与价值的相互依赖。

### 4. 深层结构（每条都要过检验）

尺度错配、概念滑转、权力与议程、代理战场、共同盲点。
每条给出：现象 → 它如何扭曲争论 → 另一种读法 → 置信度。
代理战场须写明三条启发式中哪几条成立、依据是什么；不足两条就写"未发现代理结构"。
一条都过不了检验，就写"未发现足够证据"，并说明常见解释为何不成立——这比硬凑一条更有价值。

### 5. 超越或承认

核心两条：不丢东西（双方最强的真问题都保留）、可被反驳（说得出反例条件）。
加分两条：能解释分歧来源、能改变下一步。按满足情况分四档：重构方案／候选重构／澄清式重构／不给重构。
给不出重构时，交代三件事：可了结的部分、不可化约的核心（价值权衡／经验未知／承认问题）、程序性出路与代价。

## 硬约束

1. 承重分歧类型只能一个；两个并列说明其实是两个问题。
2. 每个"本质／深层"判断都要指向话语痕迹或结构性证据，否则降级为推测。
3. 判断论证，不判断人；不诊断人格、不猜隐蔽动机。
4. 不伪造事实、数据、引文；不确定标"未核实／未知"。
5. 不用"价值观不同"当终止符：要落到具体权重、具体代价、具体制度。
6. 承认不可解：有些争议的正确结论是"这是一个需要选择的权衡"。
7. 必须报告材料限制与最可能出错处。

## 输出契约

九个模块，顺序固定：一句话判断／在争什么／立场重构／证据地图／深层结构／可了结与不可了结／超越或承认／开放问题／覆盖与限制。
字段与写法见 `references/output-template.md`。默认 1500–2500 字；短争议 800–1200 字。

## 交付前自检

- [ ] 争点命题化了，且判断了双方是否在回答同一个问题？
- [ ] 承重分歧类型只有一个，且有理由？
- [ ] 每个立场是最强版本，持该立场者能认领？
- [ ] 动机与关切的推断标了强度，没有读心？
- [ ] 引入的学科都承重，删掉会改变结论？
- [ ] 方法被审计，而不只是被命名？
- [ ] 每条深层结构都有检验，并给了另一种读法？
- [ ] "双方都忽略 X"通过了转移检验？
- [ ] 重构的档位与准入标准交代清楚，或说明为何不给重构？
- [ ] 开放问题可被回答，不是反问？
- [ ] 报告了限制与最可能出错处？
