# 输出模板

> 用法：先完成分析，再按此模板填。不要保留占位符；材料没有的字段写"材料未提供"，不要编。
> 用户只要某几块时，按他要的模块给，不要硬撑全部。

## 【一句话判断】

一句到两句：这场争议的实质是〔承重分歧类型〕，卡在〔哪一步〕，其中〔哪一部分〕其实可以了结。
末尾给置信度：高／中／低，并说依据（材料完整度、是否有可核证据、是否只有一面之词）。

写坏的样子："这是一场价值观的碰撞，双方都有道理。"——没有判断，也没有可了结的部分。

## 【在争什么】

1. **命题化**：在〔条件〕下，是否应当〔行动〕，因为〔理由〕。
2. **是否同一问题**：是／否；若不是，指出错位（原则对可行／个案对制度／动机对效果／应然对实然）。
3. **承重分歧类型**：一个；其余为辅。
4. **争议的形状**：一个问题两种答案／两个问题各说各话／一个问题的不同层次被混在一起。
5. **预设**：问题本身预设了什么；若不成立，替代问法是什么。

## 【立场重构】

每方一张卡，字段固定：

- **核心主张**（一句话，对方能接受）
- **优先价值**（保护什么、排序）
- **最强论证**（最好的版本与最好的证据）
- **依赖假设**（经验／因果／价值，逐条列）
- **代价承担者**（谁付账、是否被看见）
- **可接受的反证**（什么会让理性持有者修正；"什么都不可能"→ 信念型立场）
- **最强反驳与该立场的回应**

多方时按"立场家族"归并，注明家族内部差异（例如"自由至上派"与"温和自由派"在财产权上不同）。

写坏的样子：把一方写成"为了利益不择手段"，把另一方写成"不懂现实"——两边都成了漫画。

## 【证据地图】

1. **三分**：已确立／有争议／未知，各列条目，条目写"主张 + 状态 + 依据或缺口"。
2. **承重学科**：每个一行——学科／支撑哪条主张／缺了会怎样。列不出第三栏的删掉。
3. **方法审计**（表格）：

| 方法 | 自称在用 | 实际在做什么 | 让什么可见 | 遮蔽什么 | 最弱一环 | 对结论的影响 |
|---|---|---|---|---|---|---|

4. **相互依赖**：两处以上——哪条"事实"依赖价值预设；哪条价值判断依赖可错的经验假设。

写坏的样子：学科清单写成百科目录（经济学、伦理学、心理学各一句），删掉任何一条都不影响结论。

## 【深层结构】

有几条写几条，每条四栏：**现象 → 它如何扭曲争论 → 另一种读法 → 置信度**。

- 尺度错配（统一尺度后分歧缩小／转移）
- 概念滑转（哪个词在哪一步换义）
- 权力与议程（谁定义问题、什么被排除）
- 代理战场（三条启发式通过几条）
- 共同盲点（通过转移测试了吗）

一条都不过测试时，写"未发现足够证据"，并说明为什么这些常见解释在这里不成立——这比硬凑一条更有价值。

## 【可了结与不可了结】

- **可了结**：列子问题 + 缺什么证据 + 谁能提供。
- **不可化约的核心**：价值权衡（谁承担代价）／经验未知／承认问题，三选一，说明理由。
- **程序性出路**：若价值无法消解，能达成什么（阈值由谁定、补偿、退出权、举证责任倒置），代价是什么。

## 【超越或承认】

先写档位：重构方案／候选重构／澄清式重构／不给重构。
再逐条交代核心两条（不丢东西、可被反驳）与加分两条（解释来源、改变下一步）；缺项写明风险。

写坏的样子："其实两者可以统一：既要安全，也要民生。"——两边的真问题都还在，只是被一句话盖住了。

## 【开放问题】

一个，格式：**问题**（类型：事实／概念／规范／方法）＋ 为什么重要 ＋ 什么能回答 ＋ 现在能否回答。
不要反问句，不要"这是否值得我们深思"。

## 【覆盖与限制】（对话模式必写）

读了哪些段落、略读了哪些、归属不清处、转写误差、脱敏处理、置信度最低的判断、最可能错在哪。
