# 灵感梳理：从碎片到可检验的论述

把一组零散笔记变成**可核对**的论述：先对账，再建体系；允许"不构成体系"；批判有标准，拓展要承重，预测要能失败。

## 何时启用

- 用户贴一组零散笔记、关键词、随想、读书摘记，说"帮我梳理""看看能不能成体系""深化一下"。
- 用户要把半成品提纲发展成一篇论述，或找出碎片背后的问题。
- 用户问"这些想法之间有什么关系""我是不是在重复同一个念头"。
- 用户要求对自己的想法做批判性评价、找理论对照、提出可检验的推论。

## 何时不要启用

| 场景 | 用什么 |
|---|---|
| 会议纪要、访谈／播客提炼 | `long-dialogue-knowledge` |
| 一场争议谁有理、怎么反驳 | `controversy-analysis` |
| 概念／事实／历史问题 | `knowledge-answer` |
| 纯写作润色、改写 | 普通写作，不套本协议 |
| 从零头脑风暴（还没有材料） | 普通对话 |
| 只有一句口号或一个词 | 先问一次；仍无，直接回答 |

## 输入契约

| 需要 | 缺失时怎么办 |
|---|---|
| 碎片原文，逐条可辨 | 请用户补；补不了就标"材料不完整" |
| 几条、是否重复／矛盾 | 先合并同义项；矛盾保留，不取平均 |
| 写作语境、用途、读者 | 按可见信息推断，标"推断"；默认"给作者本人的深研稿" |
| 用户要什么：整理／判断／深化／落地 | 未说明给完整三步；只要整理则压缩评价与拓展，不删关键判断 |
| 敏感信息与事实断言 | 默认脱敏；经验断言标"未核实"，不补出处 |

不追问原则：材料可辨认就直接做，假设写在"边界与下一步"；只有材料为空、或只有一个无法判断所指的词时，才问一次。

## 工作流

### 0. 预检：先定模式与档位

问：这些碎片是在回答一个问题、几个并列的问题，还是没有共同问题？

- **单核**：一个母题，多条变体 → 建命题体系。
- **星丛**：2–4 个母题并列、有张力无统属 → 建问题场，不强行统一。
- **残篇**：太少、不相干，或只有情绪与意象 → 分别发展，或直接说"不足以成体系"。
- **提纲**：用户要文章骨架 → 命题树＋段落功能。

档位按"承重命题数"（体系里承担论证的 P／S／A），不按碎片条数：

- **轻量**（1–3 条）：九块，3000–4500 字。
- **标准**（4 条以上）：十三块，3500–5000 字；复杂至 6500，须说明。
- **提纲**：2000–3000 字。

体裁也要先判：论说型、诗性／意象型、价值／自我探索型；标准见第 3 步。

### 1. 碎片台账

逐条编号，六列：编号／原文（短引或转述）／类型／承重／读法／备注。

- **类型**：命题／问题／意象／价值／方法／经验／情绪／他人观点。只选一个主类型，副类型写备注。
- **承重**：承重／支撑／异议／游离／未定。"异议"与主题相关但质疑前提或提出竞争价值，要正面处理，不并入体系。
- **读法**：取"最强且最可能"；两种读法并置，标明选择与理由。
- 四条规则：不改写原意；台账可摘原句，正文短引 ≤30 字；重复合并、矛盾保留；先标游离。
- 结尾一句：**异质度**（高度一致／有张力／基本不相干）＋**可统合度**（可建体系／可建问题场／只能分别发展）。

判定细节与聚类测试见 `references/fragment-ledger.md`。

### 2. 命题体系

- 找共同问题；按问题聚类，不按关键词；每簇写一句簇命题。
- 主题→命题：有方向、可被反驳、有条件。单核写一个中心命题；星丛写 2–4 个极命题，不设中心；残篇跳过。
- 三层：P（中心）／S（支撑）／A（辅助）／H（悬置）。
- 机制：先做**翻译测试**（换成日常语言，信息不减就删）与 **so what 测试**（为真，什么会不一样）；再给因果链、结构、过程、激励、代价。
- 关系：支撑／递进／并列／手段—目的／前提—结论／张力／矛盾。
- 矛盾五类：定义滑转／尺度不同／经验冲突／价值权衡／观点演变。前两类可澄清；价值冲突保留，不用"辩证统一"消解。
- 边界：适用条件、反例、代价承担者、它不解释什么。
- 可辨认性：作者能认领；超出原文的地方明确标出。
- 不成立时：给问题场（2–4 极、每极最强版本、张力、为什么暂不能统一），不硬建。

### 3. 批判性评价

先判体裁，再选标准：

- 论说型：真假、机制、证据。
- 诗性／意象型：意象是否自洽、并置是否产生新联系、是否被过度解释。
- 价值／自我探索型：是否诚实、代价是否被看见、是否自相矛盾。

三轴，固定分级词，各用各的：

- **成立性**：成立／有条件成立／有趣但未证／不成立或需修正／无法判断。价值命题的"成立"指理由站得住、代价被承认，不是事实为真。
- **启发性**：高／中／低（相对这批材料；领域新意标"未检索"）。
- **可用性**：可直接用／需满足条件／仅启发／不可用。

然后五件事：强处具体到机制与连接（没有就写"未发现"）；最强反驳用反对者口吻 3–5 句再回应；未明言假设分 G（经验）／V（价值）／M（方法），逐条写"若不成立会怎样"；至少一个真实反例或反例类型；对本次梳理做自我审计（过度统一／最弱连接／我补了什么／最可能错在哪）。

判想法不判人；不谄媚、不羞辱；"有趣"不等于"成立"。

### 4. 知识拓展与推论

- **三重承重**：回答材料答不了的问题；改变或锐化某条主张；产生可检验后果。缺一删。
- 一个深谈胜于五个点名；反陈词滥调；类比只作启发，标明在哪一点失效。
- 理论出处可核对；记不清就只给名称并标"出处待核"，不编年份页码。
- **推论** 2–3 条：推理链／观察信号／时间窗／反证条件／置信度（高／中／低＋依据）。
- **预测**：逻辑推论与经验预测分开；经验预测要写条件、时间、应验信号、落空信号；给不出就写"目前只能作为解释框架"。
- **开放问题** 2–3 个：类型（事实／概念／规范／方法）／利害／回答路径／当前可否回答；不写反问。
- **回环**：拓展推翻前文，写"修正：第 X 条……"。
- **实践含义**（可选）：最小动作＋代价＋失效条件。

## 硬约束

1. 最终产出只用三个二级标题：`## 系统化论述`、`## 批判性评价`、`## 知识拓展与推论`；逐字、各一次、顺序固定；内部用加粗标签，不用三级标题（本文件里的 H3 是说明书结构，不要照搬）。
2. 不替作者做梦：材料／推断／判断分层；超出原文处标出。
3. 允许"不构成体系"；不为用上材料而硬焊。
4. 中心命题必须可被反驳；不可反驳的句子是口号。
5. 矛盾是数据；价值冲突不得用"辩证统一""更高维度"消解。
6. 深度＝机制＋条件＋代价＋反例；不是大词、排比、悖论句。
7. "有趣"不等于"成立"；三轴分开。
8. 引入的理论必须承重；类比只作启发，不作证据。
9. 预测必须可失败；开放问题必须可回答。
10. 不伪造引文、数据、文献、出处；无法核对就标"未核实"。
11. 判想法不判人；不谄媚、不羞辱；作者应能认领被推进后的版本。
12. 若拓展推翻了前文，明确写出修正，不偷偷改口。
13. 必须报告假设、未核实项与最可能出错处。

## 输出契约

**标准档**（4 条以上承重命题）十三块，顺序固定：

```markdown
## 系统化论述
**材料台账**
**这批碎片在回答什么**
**命题体系**
**矛盾与未决**

## 批判性评价
**三轴判断**
**强处**
**最强反驳与回应**
**未明言假设与反例**
**对本次梳理的自我审计**

## 知识拓展与推论
**承重的对话者**
**推论与预测**
**开放问题**
**边界与下一步**
```

**轻量档**（1–3 条承重命题，或残篇／意象为主）九块：

```markdown
## 系统化论述
**材料台账**
**逐条发展**
**为何不能统合**

## 批判性评价
**三轴判断**
**最强反驳与回应**（可省）
**对本次梳理的自我审计**

## 知识拓展与推论
**一个承重的对话者**
**一条推论或一个开放问题**
**边界与下一步**
```

**提纲档**：命题树（主张／支撑／反例／段落功能）＋一段批判＋一段拓展＋边界；不写完整台账，但每条命题要能回到碎片编号。

**编号与称谓**：碎片用 1、2、3；命题用 P／S／A／H；假设用 G／V／M。全篇不复用编号。输出中称"你"；"作者"只在协议内部使用。

**篇幅**：轻量 3000–4500 字；标准 3500–5000 字（复杂至 6500，须在"边界与下一步"说明）；提纲 2000–3000 字。写完估算字数；超出上限 10% 就删——先删重复解释，再删次要例子，最后才动"最强反驳"与"自我审计"。

**最后检查三个 H2**：`## 系统化论述`、`## 批判性评价`、`## 知识拓展与推论` 都在、各一次、顺序正确；缺一个或降成三级标题，整篇不合格。

逐块模板与"写坏的样子"见 `references/output-template.md`。

## 交付前自检

- [ ] 三个 H2 各一次、顺序正确，没有用三级标题？
- [ ] 档位按承重命题数选，字数在范围内（或说明了超长理由）？
- [ ] 台账六列齐全，承重只用五值，主类型只有一个？
- [ ] 模式判断有理由，残篇／星丛没有硬建体系？
- [ ] 中心命题可被反驳、有条件；星丛没硬设中心？
- [ ] 每条承重命题都有机制与边界？
- [ ] 矛盾五类处理，价值冲突保留？
- [ ] 三轴各用各的分级词，没有混用？
- [ ] 最强反驳具体，不是稻草人？
- [ ] 假设逐条写了"若不成立会怎样"？
- [ ] 自我审计诚实，指出了最弱连接？
- [ ] 引入的理论通过三重承重测试？
- [ ] 预测有观察信号、时间窗、反证条件？
- [ ] 开放问题有类型、利害、回答路径？
- [ ] 编号没有复用，称谓是"你"？
- [ ] 报告了假设、未核实项、最可能出错处？
- [ ] 没有开场白、总结、客套话？
