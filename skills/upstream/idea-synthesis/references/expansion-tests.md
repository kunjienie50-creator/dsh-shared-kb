# 拓展的承重测试与推论格式

拓展不是"相关知识的展示"，是"让材料里的主张变得更好或更可检验"。下面每一条都是删减标准，不是加分标准。

## 1. 三重承重测试

每引入一个理论、案例或学科，必须同时满足三条，缺一条就删：

1. **回答材料答不了的问题**：材料提出了一个问题，但靠材料自身无法回答；这个理论提供了答案或更好的问法。
2. **改变或锐化某条主张**：不是"也有类似说法"，而是"因此第 X 条要改成 Y"。写不出改写后的主张，就是没承重。
3. **产生可检验后果**：一个新预测、一个新反例、一个新区分。三者至少有一个。

通过的例子：

> 材料说"每二十秒要一次奖励"。引入"可变比率强化"后，主张从"奖励频率高"精确为"奖励时点不可预测"；可检验后果：随机时点推送应比固定时点推送引发更多主动检查；若两者无差异，这个机制不承重。

没通过的例子：

> "这与注意力经济的研究相呼应。"——它只是给材料换了一个标签，没有回答新问题，没有改变主张，没有给出可检验后果。

没通过的例子：

> "从福柯的规训理论看，算法就是现代社会的全景敞视。"——它可以贴到任何权力相关段落上；删掉后结论不变。

一个快速检验：把理论换成另一个，段落是否照样读得通？如果是，它就是装饰。

## 2. 反陈词滥调

以下词条不是禁用，而是"默认不承重"，除非你能说清它在本材料里具体改变了什么：

熵／耗散结构、范式转移、复杂性／涌现、福柯／规训、量子／观察者、洞穴寓言、麦当劳化、异化（不说明是谁的异化）、内卷（当解释用）、"现代性"（当主语用）。

它们的问题不是错，而是**可以贴到任何东西上**：贴上去不增加信息，只增加气氛。

替代办法：

- 换成一个具体机制（"切换成本按次数计费"）。
- 换成一个有时间、有地点的案例。
- 换成一个可操作的区分（"可及性"对"依赖路径"）。
- 换成一个可检验的预测。

## 3. 类比检查

类比可以启发，不能证明。用了就写清三件事：

1. **映射**：A 像 B，像在 R1、R2 上。
2. **断裂**：在 R3 上不像，所以不能推过去。
3. **用途**：这个类比是提出一个假设，还是替代一个论证？

坏例子：

> 大脑像肌肉，所以意志力会像体力一样耗尽。

问题：类比直接当结论；没有独立证据；没有说清哪里不像。

好例子：

> 若大脑像肌肉，短期耗尽后应有恢复曲线；若没有，这个类比在"恢复"这一点上失效。

## 4. 推论格式

每条推论写五栏：

| 字段 | 要求 |
|---|---|
| 推理链 | P1 → P2 → C；标出哪一步是经验前提、哪一步是逻辑蕴涵 |
| 观察信号 | 如果 C 为真，我们应该看到什么？要具体到可观察的差异 |
| 时间窗 | 多久之内？单次实验、数周、数月、数年 |
| 反证条件 | 看到什么，这条推论算落空？ |
| 置信度 | 高／中／低，并写一句"什么会提高或降低它" |

删掉标准：如果一条推论只是把中心命题换个说法，它不是推论，是复述。

## 5. 预测格式

先分清两种：

- **逻辑推论**：由命题内部推出（"若成立，则 X 与 Y 应同向变化"）。不需要时间窗，但必须是逻辑蕴涵。
- **经验预测**：关于世界，必须可观察、可失败。四要素：条件、时间、应验信号、落空信号。

写不出四要素，就不要叫预测；写"目前只能作为解释框架，不能预测"。这比硬造一个"未来会……"诚实。

## 6. 开放问题格式

每个问题写五栏：

- **问题**：一句话，问句或"是否／在什么条件下"。
- **类型**：事实／概念／规范／方法（取一个主类型；混合时写"混合（事实＋规范）"并说明哪部分是事实）。
- **利害**：回答它，会改变哪个判断或行动？
- **回答路径**：需要什么证据、论证、实验、档案？
- **当前**：能回答／部分能／不能；不能的话，缺什么？

坏例子：

> 这究竟意味着什么？值得我们深思。

好例子：

> 在控制通知频率的随机对照实验中，阅读时长是否恢复？这能区分"注意力被训练"与"时间被碎片化"两种解释。类型：事实／方法。当前：可做，但需要实验。

## 7. 回环修正

如果拓展部分推翻或修正了前面的体系，明确写：

> 修正：第 X 条，从"A"改为"B"，因为 C。

三种情况都要写：

- 理论改变了某条主张的强度（"必然"改为"在某些条件下"）。
- 理论提供了反例，某条命题需要加条件。
- 理论推翻了整个体系（这时不要硬保，改为"问题场"或"解释框架"）。

不要为了前后一致偷偷改口；梳理的价值在于判断被推进，不在于一次成型。

## 8. 置信度标尺

- **高**：直接证据、逻辑蕴涵、可重复观察。
- **中**：间接证据、单一案例、类比、尚未排除的竞争解释。
- **低**：推测、未核实、竞争解释很强、样本不明。

置信度不是语气词。写"低"时，要写清"什么会把它变成中或高"。

## 9. 交付前检查

- [ ] 每个理论都能回答"删掉它，哪条主张会变"？
- [ ] 没有把类比当证据？
- [ ] 每条推论都有反证条件？
- [ ] 经验预测有四要素，或者已降级为"解释框架"？
- [ ] 开放问题有类型、利害、路径、当前可否回答？
- [ ] 如果拓展修正了前文，写了"修正：第 X 条"？
