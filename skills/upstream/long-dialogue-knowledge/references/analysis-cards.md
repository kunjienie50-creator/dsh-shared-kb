# 分析卡片

> 这些卡片是工作底稿，不必原样贴进最终输出。它们的作用是让“提取”有固定字段，避免写成读后感。
> 所有示例均为合成，不是真实对话；不要把它们当成事实引用。

## 1. 覆盖账本

长对话先建这张表，防止只挑金句。

| 段号 | 主题 | 发言人 | 关键主张 | 是否承重 | 覆盖状态 | 置信度 | 备注 |
|---|---|---|---|---|---|---|---|
| 1 |  |  |  | 是／否 | 精读／略读／未读 | 高／中／低 |  |

“承重”指它改变了论证、结论或读者理解。承重段必须精读；非承重段可以略读，但要在【覆盖与限制】里说明。

## 3. 事实主张卡

| 字段 | 内容 |
|---|---|
| 编号 | A1 |
| 主张（转述） |  |
| 发言人／锚点 |  |
| 状态 | 对话内共识／有争议／待验证／经验／推测 |
| 证据 | 对话给了什么证据；没有就写“无” |
| 核验路径 | 什么材料能验证；谁最可能知道 |
| 备注 | 是否与别的发言冲突；是否被后续修正 |

示例（合成）：

- A1：发言人 A 认为远程办公会降低团队创新，因为“偶遇式交流”变少了。
- 状态：待验证。
- 证据：A 给了一个团队的例子，没有给比较数据。
- 核验路径：需要看同一团队远程前后的创新产出，或控制团队类型的对照研究。

## 4. 价值主张卡

| 字段 | 内容 |
|---|---|
| 编号 | B1 |
| 主张 | 什么好、什么对、什么优先 |
| 价值对象 | 效率／公平／自由／安全／共同体／尊严…… |
| 推断强度 | 明说／强推断／弱推断 |
| 证据／锚点 | 原话、用词、取舍、反复强调处 |
| 优先级 | 与什么价值冲突时，他保哪个 |
| 代价承担者 | 谁被要求让步 |
| 宣称／执行 | 他说自己重视什么 vs 论证中实际把什么放前面 |
| 备注 | 是否存在“说一套、做一套”的张力；不要急着道德判断 |

示例（合成）：

- B1：为了团队协作效率，可以接受一定程度的隐私让渡。
- 推断强度：明说。
- 优先级：效率 > 隐私。
- 代价承担者：员工。
- 备注：A 没有讨论“谁来判断让渡的边界”，这是一个缺席视角。

## 5. 方法卡

| 字段 | 内容 |
|---|---|
| 编号 | C1 |
| 方法名 | 系统思考／类比／成本收益／思想实验／案例归纳…… |
| 谁在用 |  |
| 自称用法 | 他说自己在做什么 |
| 实际用法 | 看前提、推理、证据；给锚点 |
| 前提 | 这个方法成立需要什么假设 |
| 证据标准 | 什么算支持、什么算反驳 |
| 让什么可见 |  |
| 遮蔽什么 |  |
| 使用质量 | 强／中／弱；哪一步最弱 |
| 对结论的影响 | 如果换一种方法，结论会怎样变 |

示例（合成）：

- C1：用“偶遇式交流减少”解释“创新下降”。
- 实际用法：把一个机制当作结论的证据，但没有排除“远程招聘改变了人员构成”等替代解释。
- 遮蔽：团队构成、任务类型、管理方式。
- 使用质量：弱；机制可信，但因果识别不足。

## 6. 分歧卡

| 字段 | 内容 |
|---|---|
| 编号 | E1 |
| 分歧 | 一句话 |
| 类型 | 事实／价值／定义／方法 |
| 一方 | 发言人＋主张＋锚点 |
| 另一方 | 发言人＋主张＋锚点 |
| 真正岔口 | 双方在哪一个前提上分开 |
| 什么能解决 | 什么证据、论证或定义澄清能推进 |
| 备注 | 是否只是措辞不同；是否存在假分歧 |

示例（合成）：

- E1：远程办公是否降低创新。
- 类型：事实分歧（因果）+ 方法分歧（用什么证据判断）。
- 岔口：A 把“偶遇交流减少”当作充分机制；B 要求先控制团队构成与任务类型。
- 什么能解决：同一团队的前后比较，或按任务类型分层的对照研究。

## 7. 中心论证图

用文字或箭头画，不求好看，求看清依赖关系：

```text
结论：远程办公降低创新
├─ 前提 1：创新依赖偶遇式交流
│  ├─ 证据：A 的团队案例
│  └─ 弱点：案例没有对照
├─ 前提 2：远程办公减少偶遇式交流
│  ├─ 证据：A 的个人观察
│  └─ 弱点：没有交流数据
└─ 反对意见：B 说创新产出没有下降
   └─ 回应：A 说“创新有滞后”
      └─ 弱点：滞后多久？如何排除其他因素？
```

标出：哪一环是对话内共识；哪一环最脆弱；哪一环没有证据。

## 8. 编码速查

| 你看到的 | 可能编码 | 不要写成 |
|---|---|---|
| “数据显示……” | A 事实主张 | “事实证明……” |
| “应该优先……” | B 价值主张 | “客观规律要求……” |
| “我们用第一性原理……” | C 方法 | “他用了第一性原理，所以更深刻” |
| “这里的公平指……” | D 定义 | “公平就是……” |
| “我不同意，因为……” | E 分歧 | “双方各有道理” |

## 9. 一句提醒

卡片是防止遗漏的，不是防止思考的。填完卡后要问：**这些卡之间，哪三组关系最重要？** 如果答不出，说明还停留在清单层面。
