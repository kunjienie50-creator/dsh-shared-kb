# 输出模板

> 用法：先完成分析，再按此模板填。不要保留占位符；没有材料的字段写“材料未提供”，不要编。
> 用户只要摘要时，用文末“压缩模式”，不要硬撑完整版。

## 【对话快照】

5–8 句，按这个顺序：

1. 这是什么场合、什么体裁的对话；
2. 主题与目的（区分明说／推断）；
3. 主要参与者与各自位置；
4. 对话弧：起点 → 转折 → 冲突／让步 → 结束状态；
5. 核心张力；
6. 最后一句：这场对话真正在争什么 + 置信度（高／中／低）。

不要从“随着社会的发展”开场；不要把“对话主题”写成“文章主题”。

## 【知识地图】

按 3–6 个真问题组织。每个问题用下面的骨架：

### 问题一：〔用对话自己的问法〕

- **核心主张**：〔一句话；标发言人〕
- **状态**：〔对话内共识／有争议／待验证／经验／推测〕
- **关键证据**：〔证据是什么；谁给的；锚点〕
- **反例／限制**：〔对话内已有的反例，或材料没有覆盖的边界〕
- **关系**：〔支持／反驳／修正／依赖／例证／张力；指向哪个主张〕
- **关键概念**：〔术语；谁的定义；歧义〕

重复 3–6 次。末尾附：

### 中心论证图（若有中心结论）

结论 ← 前提 1 ← 证据 1
　　　← 前提 2 ← 证据 2
　　　← 反对意见 → 回应

标出：哪一环是对话内共识；哪一环最脆弱；哪一环没有证据。

### 分歧矩阵

| 分歧 | 类型 | 一方 | 另一方 | 真正岔口 | 什么能解决 |
|---|---|---|---|---|---|
|  | 事实／价值／定义／方法 |  |  |  |  |

不要把所有分歧写成“角度不同”；如果写不出“什么能解决”，说明它可能是价值分歧。

## 【价值与方法论透视】

### 价值立场网络

按发言人／议题写，不要只列价值词。至少覆盖：

- 谁把什么排在前面；
- 谁承担代价、谁获得收益；
- 哪些价值是宣称的，哪些是论证中实际执行的；
- 哪些价值之间一致、冲突、互补或条件性兼容；
- 哪些人的视角缺席。

可用格式：

- **发言人 A**：〔价值 1〕 > 〔价值 2〕；明说／强推断／弱推断；代价落在〔谁〕身上。
- **张力**：〔价值 1〕与〔价值 2〕在〔条件〕下冲突；A 的处理方式是〔…〕，代价是〔…〕。

### 方法论工具箱

每种方法一张卡：

| 方法 | 谁在用 | 实际怎么用（锚点） | 前提 | 证据标准 | 让什么可见 | 遮蔽什么 | 使用质量 | 对结论的影响 |
|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  | 强／中／弱 |  |

只写对话里真的出现的方法；不要为了凑数把“归纳”“举例”都算成方法论。

### 知识、价值与方法的相互依赖

至少三组具体关系，不要写“三者相互影响”。可用句式：

- “〔某个事实判断〕依赖〔某个价值预设〕：只有把〔X〕算作相关／成本，才会得出〔Y〕。”
- “〔某种方法〕天然偏向〔某种价值〕：它把〔X〕变成可计算项，却把〔Y〕留在视野外。”
- “〔某个价值立场〕依赖〔某个事实判断〕：如果〔事实〕不成立，这个立场的主要论据就失效。”

## 【论证审计】

4–8 条，按重要性排序。每条尽量包含：判断 → 理由 → 锚点 → 置信度。

至少覆盖：

- **最强之处**：哪个主张证据最扎实，为什么；
- **最弱环节**：哪个前提／推理／证据最容易被击穿；
- **真正岔口**：双方到底在哪一点上分开；
- **遗漏的替代解释**：还有什么解释没有被考虑；
- **待核验事实**：哪些关键事实目前只能标“未核实”。

最后一句总体判断，标置信度。不要用“双方都有道理”收尾。

## 【我的学习笔记】

4–6 段第一人称。建议顺序：

1. **认知增量 1**：旧判断 → 新判断 → 触发发言 → 置信度 → 反证条件。
2. **认知增量 2**（如有）：同上。
3. **修正、强化与未决**：哪些被修正、哪些被强化、哪些更不确定。
4. **价值触动**：共鸣或不安；为什么；维护了什么、牺牲了什么；承担代价的一方会怎样反驳。
5. **可迁移方法**：什么场景用、第一步做什么、可能在哪失败。
6. **讨论元认知**：一条具体的，例如“先定义再争论”“把价值分歧从事实分歧里拆出来”。

不要写“我深受启发”“这场对话让我成长了很多”这类没有信息量的句子。

## 【待解之谜】

4–5 个问题。每个用这个小结构：

1. **问题**：〔疑问句〕
2. **类型**：事实／概念／规范／方法
3. **为什么重要**：〔影响哪个判断、决策或行动〕
4. **什么能回答**：〔证据、论证或经验〕
5. **现在能否回答**：能／部分能／暂时不能；原因〔…〕

至少一个问题是**反过来质疑这份总结自身框架**的，例如“我是不是把发言人的价值立场过度系统化了？”

不要写反问句；不要写“这是否值得深思”。

## 【覆盖与限制】

逐项交代：

- 读了哪些部分；略读了哪些部分；为什么；
- 哪些发言人／段落归属不清；
- 转写、翻译、剪辑可能带来什么误差；
- 哪些内容被脱敏；
- 哪些判断置信度低；
- 这份总结最可能错在哪里；
- 如果补一份材料，最想补什么。

## 压缩模式

用户只要摘要时，保留：

1. 【对话快照】；
2. 【知识地图】的 3–4 个核心问题（可删分歧矩阵）；
3. 【价值与方法论透视】各一段；
4. 【论证审计】3 条；
5. 【覆盖与限制】。

可省略【我的学习笔记】与【待解之谜】，但要在开头说明“这是压缩版，省略了反思与提问”。不要假装完整。
