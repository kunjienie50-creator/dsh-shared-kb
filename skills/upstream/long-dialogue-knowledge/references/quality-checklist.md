# 论证审计与交付检查

> 这是交付前的“找茬清单”，不是写作润色清单。每发现一个问题，先回到原文找锚点，再决定是改判断、降置信度，还是标“无法判断”。

## A. 证据与归属

- [ ] 每个关键判断都能指到具体发言人／轮次或段落？
- [ ] 转述没有偷偷加上说话人没说的限定词？
- [ ] 短引没有超过必要长度，也没有拼接不同段落？
- [ ] 说话人不明、多人重叠、代述的地方，标了“归属不确定”？
- [ ] 转写／翻译可能有误的地方，标了误差来源？
- [ ] 没有把“对话内提及”写成“已核实”？

## B. 事实主张

- [ ] 每条事实主张都有状态标签，而不是一律写成“客观知识”？
- [ ] “对话内共识”没有被写成“学界共识”？
- [ ] 个人经验没有被写成普遍规律？
- [ ] 相关性没有被写成因果？
- [ ] 样本、范围、时间、定义不同的数据，没有被硬放在一起比较？
- [ ] 外部文献／数据无法核对时，标了“未核实”，没有补出处？

## C. 价值分析

- [ ] 价值判断标了“明说／强推断／弱推断”？
- [ ] 弱推断没有写成“他其实认为……”？
- [ ] 区分了“宣称的价值”与“论证中执行的价值”？
- [ ] 写清了价值优先级：与什么冲突时，他保哪个？
- [ ] 写清了代价承担者：谁被要求让步、谁获益？
- [ ] 没有把“我听了不舒服”直接写成“他的价值观有问题”？
- [ ] 点出了缺席视角，但没有替缺席者编造立场？

## D. 方法审计

- [ ] 方法不是只被命名，而是被说明“实际怎么用”？
- [ ] 写了方法的前提与证据标准？
- [ ] 写了这种方法让什么可见、遮蔽什么？
- [ ] 判断了使用质量，而不是“用了系统思考所以更全面”？
- [ ] 说明了方法对结论的影响：换一种方法，结论会不会变？
- [ ] 没有把“举例”“归纳”“引用权威”硬包装成高级方法论？

## E. 论证质量

- [ ] 主张清楚，没有偷换概念或模糊限定？
- [ ] 证据支持结论，而不是只支持一个弱版本？
- [ ] 演绎有效；归纳足够；类比在关键点上相似？
- [ ] 因果主张处理了替代解释？
- [ ] 反方以最强版本出现，而不是稻草人？
- [ ] 价值前提没有被当成不言自明？
- [ ] 没有用“双方都有道理”代替判断？
- [ ] 证据强的一侧写强了，但没有把弱侧写成不存在？

## F. 对话动力学

- [ ] 写了谁设定议程、谁定义问题、谁转题？
- [ ] 写了谁让步、谁重申、谁回避？
- [ ] 区分了“真正交锋”与“各说各话”？
- [ ] 标出了“假共识”：双方用同一个词，但定义不同？
- [ ] 没有从一次打断推断人格或恶意？

## G. 反思

- [ ] 每个“认知增量”都有旧判断、新判断、触发点、置信度、反证条件？
- [ ] 没有把“知道了新名词”当成认知增量？
- [ ] 写了“修正／强化／更不确定”，不只报喜？
- [ ] 价值触动写了理由、代价与反方，而不只是“共鸣／不安”？
- [ ] 可迁移方法有具体场景、第一步、失败模式？
- [ ] 没有写成忏悔、感恩信或励志文？

## H. 待解问题

- [ ] 有 4–5 个问题，不是反问？
- [ ] 每个问题标了类型（事实／概念／规范／方法）？
- [ ] 写清了为什么重要、什么能回答、现在能否回答？
- [ ] 至少有一个问题在质疑这份总结自身的框架？
- [ ] 问题之间不重复，不是把同一个问题换几种说法？

## I. 覆盖与限制

- [ ] 报告了精读／略读／未读的部分？
- [ ] 报告了归属不清、转写误差、翻译误差？
- [ ] 报告了脱敏处理？
- [ ] 报告了低置信判断？
- [ ] 写了“这份总结最可能错在哪里”？
- [ ] 没有用“由于篇幅所限”掩盖漏读？

## J. 语气

- [ ] 对人善意，对论证精确；没有把“判断论证”写成“审判人”？
- [ ] 没有谄媚、站队、道德优越感？
- [ ] 没有煽情、戏剧化、伪深刻？
- [ ] 没有用“值得注意的是”“具有重要意义”这类空话凑字数？
- [ ] 允许说“我仍不同意”，但给了理由？

## K. 常见反模式

| 反模式 | 表现 | 修法 |
|---|---|---|
| 复述代替分析 | 大段“他说……他又说……” | 每条复述后加“这意味着／这依赖／这站不住” |
| 清单代替结构 | 五个主题并列，没有关系 | 加关系标签与中心论证图 |
| 价值读心 | “他暗含精英主义” | 标推断强度，给原话锚点，给其他解释 |
| 方法展览 | “用了第一性原理、系统思考、辩证分析” | 写实际用法、前提、盲点、对结论的影响 |
| 虚假平衡 | “双方都有道理” | 给判断、证据强弱、反方最强论证 |
| 反思表演 | “我深受震撼，决定改变人生” | 写具体旧判断、新判断、反证条件 |
| 问题堆砌 | 五个宏大反问 | 每个问题写类型、利害、所需证据 |
| 补写逻辑 | 说话人没说，总结者替他说圆 | 标“材料未说明”，不要补前提 |

## L. 最终十问

交付前，按顺序问自己：

1. 这场对话真正在争什么？我能用一句话说清吗？
2. 我有没有把“有人说”写成“事实如此”？
3. 我有没有把“我推断的价值”写成“他暗含的价值”？
4. 我有没有把方法名词当成方法审计？
5. 我有没有写出真正的分歧岔口？
6. 我有没有处理最强反方，而不是弱版本？
7. 我的反思有没有改变一个具体判断？
8. 我的问题能不能被回答，而不是只显得深刻？
9. 我有没有报告漏读、低置信与最可能错的地方？
10. 如果对话中最不被理解的一方读这份总结，他会说“你漏了什么”？

十问里任何一问答不上，先回去补，不要靠润色掩盖。
